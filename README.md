# Анти-ИИ Квен Академия — Физика ГВЭ-9 2027

Бесплатный офлайн-тренажёр для подготовки к ГВЭ-9 по физике в 2027 году. Проект представляет собой один HTML-файл, который работает без интернета, не требует установки и сохраняет прогресс в браузере.

## Возможности

- **Два формата письменной работы:** 100-е варианты (для большинства участников) и 200-е варианты (для слепых и слабовидящих).
- **Тренажёр с заданиями 1–16:** краткий ответ (1–14) и развёрнутый ответ с самопроверкой (15–16).
- **Устная форма:** 15 билетов по 2 вопроса (теория + практика) с критериями оценивания.
- **Справочные материалы:** плотности, теплоёмкости, удельные сопротивления, теплоты плавления/парообразования, константы.
- **Чек-лист подготовки** и **план на 25 дней**.
- **Таймер экзамена** (150 минут / 60 минут).
- **Тёмная и светлая темы**, русский и английский интерфейс.
- **Сохранение прогресса** в `localStorage` браузера.

## Технологии

- Чистый HTML + CSS + JavaScript (без фреймворков и зависимостей).
- Встроенная SVG-графика для схем и графиков.
- Адаптивная вёрстка.
